## 📖 About the Project

This repository is the practical codebase for **Selenium Online Batch 1**, covering real-world automation scenarios from scratch. It is designed as a hands-on reference for learners and practitioners who want to:

- Build a maintainable Selenium automation framework using Java and Maven
- Practice data-driven testing with Excel via Apache POI
- Execute and report test cases using TestNG
- Understand WebDriver interactions, locators, waits, and page navigation

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/imranhassanaiub/SeleniumProject-Batch1.git
cd SeleniumProject-Batch1
```

### 2. Install Dependencies

```bash
mvn clean install -DskipTests
```

### 3. Configure WebDriver Path

Update the ChromeDriver path in your test configuration or utility class:

```java
System.setProperty("webdriver.chrome.driver", "/path/to/chromedriver");
```

---

## ▶️ Running Tests

### Run All Tests via Maven

```bash
mvn test
```

### Run a Specific Test Class

```bash
mvn -Dtest=YourTestClassName test
```

### Run via TestNG XML Suite

```bash
mvn test -DsuiteXmlFile=testng.xml
```

## 📊 Test Reports

TestNG automatically generates an HTML report after every test run.

Open the report in your browser:

```
test-output/index.html
```

It includes a full breakdown of passed, failed, and skipped tests along with stack traces for failures.

## 📚 Key Concepts Covered

- **WebDriver Fundamentals** — Browser launch, navigation, window handling
- **Locator Strategies** — ID, Name, XPath, CSS Selector, LinkText
- **Waits** — Implicit, Explicit, and Fluent waits
- **TestNG Annotations** — `@Test`, `@BeforeMethod`, `@AfterMethod`, `@DataProvider`, `@BeforeClass`
- **Data-Driven Testing** — Reading test data from Excel using Apache POI
- **Headless Testing** — HtmlUnit driver for CI-friendly execution
- **Page Object Model (POM)** — Clean separation of test logic and page interactions
- **Test Reporting** — Auto-generated TestNG HTML reports
